# Jiwa-Database-SSMS-Snippets
A set of Jiwa related SQL scripts that can be used via the SQL Server Management Studio (SMSS) "Insert Snippet" mechanism.

## Installation
Copy these files into %UserProfile%\Documents\SQL Server Management Studio 22\Code Snippets\SQL\My Code Snippets (or a subfolder of). Then, you can right click in a query pane in SSMS and choose "Insert Snippet..." and then "My Code Snippets" and then choose the SQL query you want.
